# 📚 DSA in Java

A comprehensive collection of **Data Structures and Algorithms (DSA)** problems and solutions in Java. This repository documents my DSA learning journey and serves as a practical resource for mastering core algorithmic concepts.

## 🎯 About This Repository

This is a learning-focused repository where I solve and document DSA problems while simultaneously strengthening my understanding of Git and GitHub in my DSA journey. Each solution includes working implementations with clear explanations.

## 🚀 Getting Started

### Prerequisites
- Java 8 or higher installed
- Any IDE (IntelliJ IDEA, Eclipse, VS Code, or similar)
- Basic knowledge of Java syntax

### Clone the Repository
```bash
git clone https://github.com/Daksh171/DSA-in-Java.git
cd DSA-in-Java
```

### Run a Solution
```bash
# Navigate to the desired folder
cd array

# Compile the Java file
javac search_2D_II.java

# Run the program
java search_2D_II
```
